# Valentix · Portafolio de Valentina Gomes Rojas

Sitio estático (las imágenes ya van incrustadas dentro de `index.html`: aunque falte alguna imagen suelta, la página se ve completa) (HTML, CSS y JavaScript): no necesita instalación ni dependencias.
Diseñado en Figma y maquetado fiel al diseño.

## Qué incluye

Todos los archivos están en **una sola carpeta, sin subcarpetas**, para subirlos fácil a GitHub.

- `index.html`: la página completa (estilos y script dentro del mismo archivo).
- `logo.png`: logo de Valentix (también es el favicon).
- `foto-valentina.jpg`, `proyecto-1-portada.jpg`, `proyecto-2-boletin.jpg`, `proyecto-2-paginas.jpg`, `uniplata-bienvenida.png`, `uniplata-celular.png`, `uniplata-escritorio.png`, `uniplata-pantallas.png`: imágenes de los proyectos.
- `404.html`, `robots.txt`, `LICENSE`, `README.md`.
- `.nojekyll` y `.gitignore`: archivos ocultos (empiezan con punto). En Mac/Windows pueden no verse; actívalos con *Cmd + Shift + .* (Mac) o *Ver > Elementos ocultos* (Windows).

## Publicar en GitHub Pages

1. En github.com crea un repositorio nuevo y déjalo **público**.
2. Descomprime el `.zip` y sube **el contenido de la carpeta** (no el `.zip`): *Add file > Upload files*, arrastra todos los archivos (incluidos los ocultos) y haz *Commit changes*.
3. Ve a *Settings > Pages*, en *Source* elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`, y guarda.
4. En uno o dos minutos el sitio aparece en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Importante

- GitHub distingue mayúsculas y minúsculas: **no cambies los nombres** de los archivos (`logo.png` no es lo mismo que `Logo.png`).
- `index.html` debe quedar en la raíz del repositorio, no dentro de otra carpeta.
- Las tipografías (Cinzel, Playfair Display y Space Grotesk) se cargan desde Google Fonts, por eso hace falta conexión a internet para verlas.
